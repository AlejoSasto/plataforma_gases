# Informes

## Generar

En Informes elige el tipo y las fechas y pulsa generar. También puedes pedirlo en Preguntar si tu rol puede descargar informes.

## Descargar

Cuando el archivo está listo, pulsa Descargar. El pie del PDF dice el periodo, hasta qué fecha hay datos y si el origen es histórico o en vivo.
