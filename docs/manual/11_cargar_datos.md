# Cargar datos

## Cargar archivos

En Cargar datos elige el archivo de lecturas y espera el mensaje de resultado. Si falta una columna o hay un valor imposible, el sistema lo rechaza y explica el motivo.

## Calidad

En Calidad de los datos ves lecturas marcadas y huecos. Eso no rellena números inventados: solo señala lo que hay que revisar.
