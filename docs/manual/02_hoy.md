# Hoy

## Leer el estado

Hoy muestra cada equipo con una palabra y un color: Normal, Vigilar, Actuar ya, Evacuar o Sin datos. El color nunca va solo: siempre va con la palabra.

## Ahora y lo que viene

La línea continua es lo que marcó el equipo. La línea punteada es lo que se espera en los próximos minutos. Si no hay expectativa, la pantalla lo dice.

## Sala

La sala de control muestra lo mismo en grande, para verlo de lejos. No cambia las decisiones: solo se lee.
